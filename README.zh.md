# skills

我个人创作并维护的一组 Skills。

---

## 快速开始

运行以下命令完成安装：

```bash
npx skills@latest add tangsong404/skills
```

## 技能概述

### gen-spider

面向爬虫开发与网页自动化的代码生成技能，采用“先探索、后实现”的流程：智能体会先完整走通用户需求，再基于实测结果沉淀经验文档与请求/响应 Schema，为后续 To-PRD 与 TDD 阶段提供可靠输入。

与 [agent-browser](https://github.com/vercel-labs/agent-browser) 技能配合使用时效果最佳。

```bash
npx skills@latest add tangsong404/skills/gen-spider
```

### everything-find

通过 Everything 搜索替代 `where` 等原生检索指令，提升智能体在全局或大范围路径中的搜索效率。

使用该技能前，请确保当前系统为 Windows。

```bash
npx skills@latest add tangsong404/skills/everything-find
```

### ragret

为我开发的知识库应用 [RAGret](https://github.com/tangsong404/RAGret) 提供智能体查询支持。

使用该技能前，请确保您或您的组织已部署 RAGret 应用。

```bash
npx skills@latest add tangsong404/skills/ragret
```
