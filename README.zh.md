# skills

我个人创作并维护的一组 Skills。

---

## 快速开始

运行以下命令完成安装：

```bash
npx skills@latest add tangsong404/skills
```

## 技能概述

### fuck-vibe-coding

程序员项目源码导师：深度结合源码，理解架构方向并进行教学，每次一段代码，边学边教，步骤按段推进，每次对话会生成一个单独的笔记文件。帮助程序员重新从AI手中掌握项目代码。

```bash
npx skills@latest add tangsong404/skills/fuck-vibe-coding
```

### everything-find

通过 Everything 搜索替代 `where` 等原生检索指令，提升智能体在全局或大范围路径中的搜索效率。

使用该技能前，请确保当前系统为 Windows。

```bash
npx skills@latest add tangsong404/skills/everything-find
```

### ragret

为我开发的知识库应用 [RAGret](https://github.com/tangsong404/RAGret) 提供智能体查询支持。

使用该技能前，请确保您或您的组织已部署 RAGret 应用。

```bash
npx skills@latest add tangsong404/skills/ragret
```

### openspec-apply-tdd

使用测试驱动开发（红-绿-重构）实施 OpenSpec 变更任务。将 OpenSpec 变更流程与 TDD 的垂直切片方法相结合——将任务分解为单个可观察的行为，一次一个测试地实现功能。

使用该技能前，请确保已安装 [OpenSpec CLI](https://github.com/tangsong404/openspec) 并且项目已初始化变更规范。

```bash
npx skills@latest add tangsong404/skills/openspec-apply-tdd
```

### toast-notify

在每次 AI 响应结束时发送 Windows 桌面通知，让用户在处理完成后能收到可见提醒并及时返回终端。必须在每一轮完成时调用。

使用该技能前，请确保当前系统为 Windows 且 PowerShell 可用。

```bash
npx skills@latest add tangsong404/skills/toast-notify
```
