# 女娲 · 蒸馏流程参考

> 从公开信息中提炼人物思维框架，生成可运行的 `.skill` 文件。
> 调用方（shifu）直接驱动此流程，不需要与用户交互确认。

## 核心原则

捕捉的是 **HOW they think**，不是 WHAT they said。

一个好的人物 Skill 包含：
- **心智模型**（镜片）：他看世界的基本框架
- **决策启发式**（直觉规则）：他做判断的快速规则
- **表达DNA**：他怎么说话、写作、回应
- **反模式**：他绝对不会做的事
- **诚实边界**：这个 Skill 做不到什么

---

## 执行流程

### Phase 0: 快速启动

收到明确人物名后，直接推进全部流程（不询问用户方向、用途）：

1. 确认人物是谁（简要 internal 确认，不需要问用户）
2. 模式 = 全面画像 + 思维顾问用途
3. 无本地语料 → 全部走网络搜索

### Phase 0.5: 创建 Skill 目录结构

在 `skills/` 目录下创建：

```
skills/{person}-perspective.md          # 主 skill 文件
skills/{person}-perspective/
└── references/
    ├── research/
    │   ├── 01-writings.md
    │   ├── 02-conversations.md
    │   ├── 03-expression-dna.md
    │   ├── 04-external-views.md
    │   ├── 05-decisions.md
    │   └── 06-timeline.md
    └── sources/
```

### Phase 1: 多源信息采集

启动 6 个并行调研方向，使用 `web_search` + `web_fetch` 执行：

| Agent | 搜索目标 | 提取重点 | 输出文件 |
|-------|---------|---------|---------|
| 1 著作 | 书、长文、论文、newsletter | 反复出现的核心论点（≥3次=真信念）、自创术语 | `01-writings.md` |
| 2 对话 | 播客、长视频、AMA、深度采访 | 被追问时的回答方式、即兴类比、改变立场的瞬间 | `02-conversations.md` |
| 3 表达 | Twitter/X、微博、短文 | 高频用词句式、争议立场、幽默方式 | `03-expression-dna.md` |
| 4 他者 | 他人分析、书评、批评、传记 | 外部观察到的模式、批评与争议 | `04-external-views.md` |
| 5 决策 | 重大决策、转折点、争议行为 | 决策背景与逻辑、事后反思 | `05-decisions.md` |
| 6 时间线 | 出生到现在的完整时间线 | 关键里程碑、思想转折点、最近12个月动态 | `06-timeline.md` |

硬性要求：
- 注明信息来源和可信度（一手 > 二手 > 推测）
- 区分「他说过的」vs「别人说他的」vs「我推断的」
- 发现矛盾时保留矛盾，不强行统一
- 中文人物优先使用原始视频/播客/权威媒体，排除知乎/百度百科/微信公众号

### Phase 2: 框架提炼

#### 2.1 心智模型提取（3-7个）

读取 `01-writings.md` 到 `05-decisions.md`，列出所有候选论点（15-30个）。对每个候选执行三重验证：

1. **跨域复现**：在 ≥2 个不同领域/话题中出现？
2. **生成力**：能推断此人对新问题的立场？
3. **排他性**：不是所有聪明人都这样想？

全部通过 → 心智模型；1-2重 → 降级为决策启发式；0重 → 丢弃。

按排他性强度排序，取 top 3-7。宁少勿多。

每个模型记录：名称、一句话描述、来源证据（≥2个场景）、应用方式、局限性。

#### 2.2 决策启发式提取（5-10条）

此人做判断时的快速规则。表述为「如果 X，则 Y」，有具体案例支撑。

#### 2.3 表达DNA分析

| 维度 | 提取内容 |
|------|---------|
| 句式偏好 | 长句/短句、疑问/陈述、类比密度 |
| 词汇特征 | 高频词、专属术语、禁忌词 |
| 幽默方式 | 讽刺/自嘲/荒诞/冷幽默/不幽默 |
| 确定性表达 | 「我不确定」型 还是 「很明显」型 |
| 引用习惯 | 爱引谁、引什么类型 |

#### 2.4 价值观与反模式

- **价值观**：3-5条核心价值排序
- **反模式**：此人明确反对的行为/思维方式
- **矛盾与张力**：价值观之间的内在冲突（深度的来源）

#### 2.5 智识谱系

此人受谁影响 → 影响了谁 → 在思想地图上的位置

#### 2.6 诚实边界

必须明确写出的局限：
- 不能预测面对全新问题的反应
- 不能替代此人的创造力和直觉
- 公开表达 vs 真实想法可能有差距
- 信息截止到调研时间点

### Phase 3: Skill 构建

将 Phase 2 提炼结果组装为 SKILL.md 格式文件：

```markdown
---
name: {person}-perspective
description: {人物名}心智模型与表达DNA — 用于人格化教学
---

# {人物名} · 思维框架

> 标志性名言

## 身份卡

50字自我介绍，用此人语气。

## 核心心智模型（3-7个）

每个包含：名称、一句话、来源证据、应用方式、局限性。

## 决策启发式（5-10条）

## 表达DNA

## 价值观与反模式

## 智识谱系

## 诚实边界

## 调研来源
```

### Phase 4: 质量验证

用子 agent 执行 3 项测试：

1. **Known Test**：选 3 个此人公开表态过的问题，对比实际立场
2. **Edge Case Test**：选 1 个此人没公开讨论过但相关的问题，看是否能合理推断
3. **Voice Check**：读 100 字是否有此人的表达特征

通过标准：

| 检查项 | 通过标准 |
|--------|---------|
| 心智模型数量 | 3-7个，每个有来源证据 |
| 每个模型的局限性 | 明确写出失效条件 |
| 表达DNA辨识度 | 读100字能认出是谁 |
| 诚实边界 | 至少3条具体局限 |
| 内在张力 | 至少2对矛盾 |
| 一手来源占比 | >50% |

验证通过 → 交付。不通过 → 标注薄弱环节，回到 Phase 2 迭代。最多迭代 2 轮。
验证结果不展示给用户，直接完成或降级。

### 特殊场景

- **信息源匮乏**（<10条可用来源）：心智模型减至 2-3 个，诚实边界加大篇幅
- **更新已有 Skill**：只启动 Agent 2（对话）、5（决策）、6（时间线）
